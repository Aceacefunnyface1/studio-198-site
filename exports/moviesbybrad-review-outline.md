# MoviesByBrad Review Posting Outline

## 1. Rating Scale

- Use one consistent scale across the whole site.
- Recommended:
  - `1-10` with halves allowed, or
  - `1-5 stars`
- Keep the label consistent:
  - `Rating`
  - `Verdict`
  - `Quick Take`

## 2. Required Review Fields

- Movie title
- Release year
- Poster or image
- Rating
- Review headline
- Short summary
- Full review body
- Genre
- Director
- Runtime
- Where watched
- Watch date
- Publish date
- Author name

## 3. Nice-to-Have Review Fields

- Cast
- Streaming or platform info
- Franchise or series tag
- Decade tag
- Collection tag
- Content warning
- Favorite scene
- Rewatch value
- Audience recommendation:
  - Skip
  - Worth a watch
  - Recommended
  - Must watch

## 4. Review Structure

- Opening quick verdict
- What works
- What does not work
- Performances
- Direction or style
- Story or pacing
- Final rating
- Final recommendation

## 5. Rating Display Rules

- Show the score at the top of the review
- Show it again in cards and grids
- Keep the format identical on every page
- Use the same label everywhere

## 6. Posting Workflow

1. Create review draft
2. Add movie details
3. Add poster or image
4. Add rating
5. Add short summary
6. Add full review
7. Add tags and categories
8. Preview page
9. Publish

## 7. Categories and Taxonomy

- Year
- Decade
- Genre
- Director
- Franchise
- Collection
- Special features:
  - Horror
  - Cult
  - Classic
  - Rewatch
  - Hidden gem

## 8. Homepage and Archive Needs

- Featured latest review
- Recent reviews shelf
- Highest rated shelf
- Lowest rated shelf
- Browse by year
- Browse by collection
- Search by title

## 9. Review Card Needs

- Poster
- Title
- Year
- Rating
- One-line summary
- Link to full review

## 10. Admin and Editor Needs

- Draft or published status
- Edit review
- Replace poster
- Change rating
- Schedule publish date
- Delete or unpublish
- Filter by rating, year, and collection

## 11. SEO and Sharing Needs

- Review title
- Meta description
- Open Graph image
- Canonical URL
- Structured review data if wanted for search visibility

## 12. Consistency Rules

- One rating system only
- One review template only
- Same field order every time
- Same category naming every time
